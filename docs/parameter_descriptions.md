# SPARK Parameter Descriptions

| Parameter | Description |
|---|---|
| ΔBIC > 10 | Threshold for strong multimodality evidence |
| networkType = signed | Signed pathway co-activity network |
| SFT.R.sq > 0.8 | Soft-threshold selection criterion |
| resolution_grid | Leiden resolution search space |
| n_boot | Number of bootstrap iterations |
| PC1 scores | Principal component-derived module scores |

## Notes

These parameters represent the default SPARK configuration used for transcriptomic module discovery.
